# Kinpower Tech Limited Website

Static GitHub Pages website for Kinpower Tech Limited's broadcast and production equipment catalog.

## Publish with GitHub Pages

1. Create a new public repository on GitHub named `kinpower-website`.
2. Upload the contents of this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. The site will be available at:

   `https://chipondajames-sudo.github.io/kinpower-website/`

The contact form is currently a front-end demo. Connect it to a form service or backend before using it for live enquiries.
